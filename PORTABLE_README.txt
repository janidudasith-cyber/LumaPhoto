LumaPhoto Portable
==================

1. Extract this entire ZIP to a folder you control, such as Documents\LumaPhoto.
2. Do not run LumaPhoto.exe from inside the ZIP preview.
3. Open LumaPhoto.exe.

Windows may show a security prompt for a newly downloaded unsigned app. Only
continue if you downloaded this ZIP from the official LumaPhoto release page.

To update, download the newest ZIP, extract it to a new folder, and open the
new LumaPhoto.exe. Your photos are never stored in the application folder.

Optional background-removal models downloaded by the app are stored in:
%LOCALAPPDATA%\LumaPhoto\Models

This portable package deliberately excludes research-trained FiveK/PPR10K
enhancement models. Auto Enhance remains available through its rule-based mode.
